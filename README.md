# HonorLocalOTA

荣耀 MagicOS「软件更新」（`com.hihonor.ouc`）的 Xposed 模块。把被隐藏的本地更新入口恢复出来，并按需屏蔽新版本提示、强制向服务器请求全量包。

## 功能

| 功能 | 说明 |
| --- | --- |
| 本地更新入口 | 在「软件更新」的三点菜单里恢复本地安装包入口 |
| 屏蔽新版本提示 | 检查更新时压成「无新版本」，不再提示升级 |
| 强制全量包 | 向服务器请求完整包（10 GiB 量级），而不是增量包（1~2 GiB） |
| 重启软件更新 | 设置页里以 root 停止并重新拉起「软件更新」进程 |

两个开关的相互关系：

- 「屏蔽更新」与「强制全量包」互斥。打开「强制全量包」时「屏蔽更新」不生效，设置页会在旁边提示「已被强制全量包覆盖」。
- 设计上不在程序里偷偷改写另一个开关，避免出现「是谁把开关关掉的」这种难以追溯的状态。

## 要求

- **LSPosed**，且框架需支持 libxposed API 102（模块声明 `minApiVersion=101`、`targetApiVersion=102`）
- **root**（原因见下一节）
- 作用域：`com.hihonor.ouc`（「软件更新」）

> 关于框架版本：`LSPosed/LSPosed` 官方仓库的安装包停留在较早的版本，未必支持 API 102。若模块在 LSPosed 中不显示或无法启用，请先确认框架是否支持 libxposed 102。

## 为什么需要 root

模块的开关配置存在 `/data/local_ota/module_switch.conf`，这个目录的 SELinux 标签是 `local_ota_file`。

从系统策略里能查到，允许访问该标签的域只有四个：`adbd`、`platform_app_all`、`shell`、`update_engine`。

- 「软件更新」自身跑在 `platform_app_all` 域，本来就能读写，所以 hook 侧不需要额外权限
- 模块的设置页跑在 `untrusted_app` 域，**不在放行名单里，连读取属性都不允许**，因此必须通过 `su` 访问

没有 root 时，设置页会显示「root 不可用，开关无法保存」，而不会静默失败。

## 使用方法

1. 安装 APK
2. 在 LSPosed 中启用本模块
3. **在 LSPosed 里为该模块勾选作用域「软件更新」**（见下方注意事项）
4. 重启手机，或强制停止「软件更新」
5. 打开模块设置页，确认显示「root 可用」以及两个开关的状态

> **作用域必须手动勾选。** 模块的 `META-INF/xposed/module.prop` 声明了 `staticScope=true`，含义是作用域不由模块自行声明，必须由用户在管理器里手动指定。
>
> 如果只启用了模块却没勾作用域，模块的代码**不会被注入到「软件更新」进程**。此时设置页的开关能正常读写（因为它走 root 直接写配置文件），但 hook 完全没生效——表现为屏蔽无效、本地更新入口不出现、勾了全量包仍然收到增量包。这不是 bug，是配置遗漏。

## 使用本地更新

1. 把全量包复制到 `/data/local_ota/`
2. 文件名必须包含 `update_full_`（系统用 `.*update_full_.*\.zip` 做全串匹配，名字不含这段就永远扫不到）
3. 该分区剩余空间需不少于 30 GiB，否则系统会静默跳过
4. 打开「软件更新」→ 三点菜单 → 本地更新

## 如何判断全量包是否生效

荣耀的「软件更新」在检查更新时显示的目标包体积可以直接区分两种包：

- **10~11 GiB** → 全量包，说明 `r9.w1.x2()` 的 hook 生效
- **1~2 GiB** → 增量包，说明 hook 未生效（先检查作用域是否勾选）

## 重启软件更新按钮的用途

设置页里的「重启软件更新」按钮以 root 执行 `am force-stop` + `am start`。

它**不是**为了「让开关生效」——两个开关是读时生效的，`SwitchStore` 每次都会真正去读配置文件，没有缓存，改完开关立刻生效，不需要重启。

它真正解决的是：

- 刚在 LSPosed 里启用或更新模块，已经跑着的「软件更新」进程里没有新代码，三点菜单看不到本地更新入口
- 「软件更新」界面卡住

## 兼容性

在荣耀 AAK-AN00（MagicOS 11 / Android 17）上测试通过，对应「软件更新」版本 2.1.1.1（versionCode 205）。

不同机型、不同系统版本的「软件更新」类名与结构可能不同，模块按上述版本实现，未覆盖的情况可能不生效。
